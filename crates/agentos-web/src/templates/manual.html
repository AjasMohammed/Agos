Agent Manual

Runtime documentation exposed by the agent-manual built-in tool

What this is

Agents call the agent-manual tool with a JSON payload to retrieve structured OS documentation (permissions, memory tiers, events, commands, errors, coordination, and more) without bloating the system prompt. This page is a human-readable overview; the authoritative content is whatever the running kernel returns from the tool.

To browse installed tools and manifests in the UI, use Tools.

Example tool call
{"section": "index"}

Use {"section": "tool-detail", "name": "<tool-name>"} for full schema for one tool, and {"section": "suggest", "query": "…"} for intent-based tool hints.
